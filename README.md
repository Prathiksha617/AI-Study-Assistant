# 🎓 AI Study Assistant

## 📌 Project Description

AI Study Assistant is an AI-based educational application designed to help students with their learning and study activities. It provides an interactive platform where students can ask questions, get AI-generated answers, and use study materials for better understanding.

## 🎯 Objectives

* To provide an intelligent study assistant for students.
* To answer students' academic questions.
* To help students understand study materials.
* To provide an easy-to-use learning interface.
* To support students in improving their learning experience.

## ✨ Features

* 🤖 AI-based question answering
* 📚 Study assistance
* 📄 PDF/document learning support
* 🔍 Semantic search
* 📝 Quiz and practice support
* 📊 Student progress support
* 💬 Interactive user interface

## ⚙️ Installation

### 1. Clone the repository

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
```

### 2. Open the project folder

```bash
cd AI_Study_Assistant
```

### 3. Create a virtual environment

```bash
python -m venv venv
```

### 4. Activate the virtual environment

For Windows PowerShell:

```bash
venv\Scripts\Activate.ps1
```

### 5. Install the required packages

```bash
pip install -r requirements.txt
```

## ▶️ Run the Application

Run the following command:

```bash
streamlit run app.py
```

The application will open in the web browser.
